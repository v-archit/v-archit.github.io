Tower Defense AI

Goal Oriented Action Planning AI System

Role: Lead Programmer (Artificial Intelligence in Games)
Engine: Unity (C#)
Platform: Windows

Overview

Tower Defense AI is a prototype demonstrating the use of Goal Oriented Action Planning (GOAP) to create adaptive and strategic enemy behaviour in a strategy game environment. The AI dynamically evaluates game states and determines the optimal sequence of actions to achieve a target goal state.
Players must destroy all opponent towers while managing resources and deploying units. Different unit types serve specific purposes such as combat, siege operations, and resource gathering.

Architecture

Game Manager
   |-- GOAP Planner
   |     |-- Goal Evaluator
   |     |-- Action Selector
   |
   |-- Resource Manager
   |
   |-- Unit Controller

The GOAP planner continuously evaluates the current game state and determines a sequence of actions required to achieve a target goal. Actions include resource gathering, unit production, and attacking enemy structures.

Key Systems

GOAP Planning System

The AI determines the optimal sequence of actions by evaluating available actions and their effects on the world state. This allows enemies to adapt their strategy dynamically depending on the current game conditions.

Resource & Unit Management

AI agents gather resources and create units to achieve strategic goals. Different unit types are used for combat, siege operations, and resource generation.

Highlights

Challenges & Solutions

AI Decision Complexity

Large numbers of possible states made brute force decision-making infeasible. GOAP planning was implemented to efficiently search for optimal action sequences.

Balancing Resource and Combat Behaviour

AI needed to dynamically choose between resource gathering and attacking. State priorities were introduced to balance strategic decisions.

Performance & Optimization

  • Optimized planning evaluation to minimize runtime overhead
  • Used coroutine-based execution for efficient action processing
  • Maintained stable performance with multiple active AI agents
