ViRaasat

Mixed Reality Cultural Heritage Installation

Role: Lead Developer
Platform: Mixed Reality Interactive Installation
Engine: Unity (C#) + Hardware Integration

Overview

ViRaasat is a mixed-reality installation designed to showcase UNESCO World Heritage sites through interactive projection mapping and digital walk-through experiences. Each installation combines a to-scale 3D printed monument with a Unity-based interactive simulation projected onto the physical model.
Visitors can explore the monument through a virtual walkthrough while interactive elements such as voice commands, computer vision, and physical sensors enhance the experience.

System Architecture

                            User Interaction
                               |-- Alexa Voice Commands

                               |-- Physical Sensors (Arduino)

                            Unity Application
                               |-- Navigation System
                               |-- Interactive Walkthrough

The system integrates real-world hardware inputs and voice interfaces with a Unity-based virtual environment to create an immersive mixed-reality experience projected onto physical monument models.

Key Systems

Projection Mapping Engine

Digital environments were aligned with physical monument models using projection mapping to create the illusion of an animated physical structure.

Voice Interaction System

Alexa Skills integrated through AWS allowed users to interact with the installation using natural language commands.

Computer Vision Integration

OpenCV was used to synchronize camera input with Unity game logic, allowing physical movement to influence virtual interactions.

Highlights

Challenges & Solutions

Synchronizing Physical and Digital Systems

Projection mapping required precise alignment between physical models and the digital environment. Calibration tools were developed to maintain synchronization.

Hardware Integration Stability

Integrating OpenCV, Arduino hardware, and AWS services required careful event handling to prevent latency and maintain responsive interactions.

Performance & Optimization

  • Optimized Unity scenes for stable performance during live installations
  • Reduced latency between hardware inputs and virtual interactions
