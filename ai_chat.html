The AI Story

A Narrative Decision System Built in Unity Using Ink and C#

Role: Lead Programmer (Production Studio)
Engine: Unity (C# + Ink)
Platform: Windows
Team Size: 4

Overview

The AI Story is a 2D narrative-driven side-scroller where the player takes the role of a programmer who has developed an AI that begins malfunctioning. The game simulates the passage of time through daily conversations between the programmer and the AI along with small tasks that help monitor the AI’s health. Player decisions affect the AI's behavior and determine how the story progresses.

Architecture

                            Game Manager
                               |-- Dialogue Manager
                               |     |-- Ink Script Loader
                               |     |-- Choice Processor
                               |
                               |-- AI State Manager
                               |
                               |-- UI Dialogue Controller

Narrative scripting is handled through Ink files while Unity scripts manage state transitions and dialogue presentation. This separation allows narrative designers to modify story content without changing gameplay code.

Key Systems

Dialogue Engine

Implemented a dialogue system that parses Ink scripts dynamically and presents branching conversation options to the player.

Decision Tracking System

Player choices are stored in persistent state variables that influence future narrative branches and determine the final ending.

Daily Task System

Gameplay alternates between conversation segments and diagnostic tasks representing AI health checks. These tasks affect the AI's internal state.

Challenges & Solutions

Managing Branching Dialogue

Dialogue complexity increased as more branches were added. Ink scripting allowed narrative logic to remain separate from gameplay code, simplifying iteration.

Persistent Story State

A centralized state manager was implemented to maintain player choices across scenes and ensure consistent narrative progression.

Performance & Optimization
