VRchive

Virtual Reality Interactive Experience

Role: Lead Developer
Engine: Unity (C#) + SteamVR
Platform: HTC Vive VR System

Overview

VRchive is a virtual reality experience built using the SteamVR API in Unity and deployed on the HTC Vive headset with two base stations and wireless controllers.
The experience is designed as a treasure hunt game set inside a digitally reconstructed version of Sabarmati Ashram. Players must locate hidden objects that emit sound cues and interact with them using VR controllers.

Key Systems

VR Interaction System

Players interact with objects using handheld controllers, grabbing and manipulating items using physics-based interactions.

Audio-Based Navigation

Hidden objects emit sound cues that guide the player through the environment, encouraging exploration.

Environment Navigation

NavMesh AI systems were used to manage environmental movement and interactive behaviours within the VR scene.

Challenges & Solutions

VR Interaction Precision

Ensuring accurate object grabbing and interaction required fine-tuning of controller mapping and physics parameters.

Player Orientation in VR

Sound cues and spatial design were used to guide players through the environment without traditional UI elements.
