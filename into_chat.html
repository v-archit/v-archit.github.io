Overview

Into The Babyverse is a zero-gravity 6DOF space shooter developed as a capstone project in Unreal Engine. The primary focus was engineering modular gameplay systems including custom 6DOF movement, spline-based enemy pathing, physics-driven environmental interactions, and structured game state management. The project emphasizes system architecture, performance stability, and gameplay responsiveness.

Architecture

                                GameInstance
                                   |-- GameMode
                                   |__ PlayerController
                                   |     |-- 6DOF Pawn
                                   |           |-- Movement Component
                                   |           |-- Weapon Component
                                   |           |-- Interaction Component
                                   |-- SplineManager
                                   |-- UI Manager

The architecture separates movement, combat, AI pathing, and UI into modular components. Systems communicate through Unreal delegates and event-driven logic to reduce tight coupling. This structure allows scalability and easier debugging of isolated subsystems.

Key Systems

6DOF Movement System

Implemented a custom 6DOF movement controller using C++ with quaternion-based rotations to avoid gimbal lock. The system includes smoothed acceleration curves, velocity dampening, and inertia tuning for improved player comfort.

Spline-Based Enemy Pathing

Developed a spline manager that assigns runtime spline paths to AI entities. Enemy movement is updated efficiently with adjustable speed curves and optimized tick frequency.

Physics & Blast Interaction System

Built a radial impulse system that applies controlled force to nearby actors. Collision filtering prevents unnecessary physics calculations on distant objects, maintaining stability during large-scale blast events.

Cutscene & Event System

Integrated Unreal Sequencer with C++ event triggers. Camera blending and event callbacks allow smooth transitions between gameplay and cinematic sequences.

Challenges and Solutions

  • Menu State
  • Onboarding State
  • Gameplay State
  • Victory / End State

Implemented a state-driven architecture where transitions are managed via controlled event dispatching. UI and gameplay systems remain decoupled to prevent unintended cross-state dependencies.

Game Loop & State Management

6DOF Control Stability

Initial implementation resulted in disorienting rotational behavior. Introduced velocity dampening and smoothing curves to stabilize movement without reducing responsiveness.

Physics Jitter During Blast Events

Large radial impulses caused unstable interactions. Implemented filtered collision queries and controlled impulse scaling to ensure consistent physics behavior.

Performance & Optimization

  • Maintained 75–90 FPS on mid-tier GPU hardware
  • Reduced unnecessary tick updates on idle actors
  • Optimized spline update frequency
  • Minimized physics calculations during high-load events
